### Загрузите и запустите у себя в компьютер бэкенд ссылка будет ниже

Ссылка: https://github.com/Shokhzod-25/Coin-View-Backend.git

### Загрузка

``` bash
git clone https://github.com/Shokhzod-25/Coin-View-Frontend.git
```

### Перейдите в корневую директорию проекта

```bash
cd Coin-View-Frontend
```
### Установка нужых библиотек

```bash
npm i
```
### Запуск

```bash
npm run dev
```
